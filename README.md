## 🚀 Pages Overview

- **`index.html`**: Homepage showcasing company services, hardware sales, customer reviews, vision & mission, and direct contact details.
- **`cloud.html`**: Cloud migration, Microsoft 365, Google Workspace, cloud backups, and Tally On Cloud enterprise solutions.
- **`crm.html`**: Dedicated Laundry POS and CRM workflow software with feature breakdown and demo booking.
- **`cyber.html`**: Enterprise network security, endpoint defense, firewall setup, employee training, and security audit packages.
- **`digital-marketing.html`**: Digital marketing packages, SEO solutions, and integrated EmailJS consultation booking form.
- **`about.html`**: Company profile and history.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript**: Fast, dependency-light static architecture.
- **Tailwind CSS & Vanilla CSS**: Modern utility styling and customized glassmorphism designs.
- **Bootstrap Icons**: Lightweight vector iconography.
- **EmailJS**: Client-side consultation booking without backend dependencies.
